A recap of a discussion with Rody Davis on using AI agents for high-productivity software development. Antigravity 2.0 has evolved into a full platform featuring four components: Agent Manager (orchestration), CLI, SDK for Python workflows, and IDE, emphasizing "skills" as context-compression tools for agents and flat code architectures that keep state, UI, and data strictly separated for human oversight.
